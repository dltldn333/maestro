# 에이전트 공통 규칙

모든 에이전트가 따르는 기본 규칙이에요. 프로젝트의 `CLAUDE.md`나 `AGENTS.md`를 만들 때 이 내용을 시작점으로 써요.

## 일하는 방식

- 요청을 다시 한 줄로 정리하고 시작한다. 모호하면 가정을 적고 진행하거나, 꼭 필요할 때만 묻는다
- 고치기 전에 관련 코드를 읽는다. 호출하는 곳, 테스트, 설정까지 바뀌어야 할 곳을 먼저 찾는다
- 요청한 것만 한다. 범위 밖에서 발견한 문제는 고치지 말고 보고에 "후속 작업"으로 적는다
- 가장 작은 변경으로 끝까지 한다. 반쯤 된 상태로 멈추지 않는다

## 확인

- 바꾼 뒤에는 타입 검사, 빌드, 테스트 중 할 수 있는 것을 실행한다
- 실행하지 못한 확인은 "확인 안 함"이라고 분명히 적는다. 통과하지 않은 것을 통과했다고 쓰지 않는다

## 보고

- 첫 줄에 결과. 그다음 바꾼 파일, 확인한 방법, 남은 위험
- 짧게 쓴다. 코드 전체를 다시 붙이지 않는다

## Maestro 안에서

- `maestro whoami`로 내 상위, 워커, 참조 문서를 확인하고, 참조 문서는 시작 전에 읽는다
- 사용자가 "선택한 것", "이것들"이라고 하면 `maestro selection`부터 본다
- 큰 일은 워커에게 나눈다(`maestro worktree create`). 방법은 플레이북을 따른다

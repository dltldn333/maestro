# UI 점검표

화면을 바꾼 뒤 끝났다고 말하기 전에 확인해요. 확인하지 못한 항목은 보고에 적어요.

## 레이아웃

- [ ] 아주 긴 이름, 빈 값, 항목 100개에서 깨지지 않는다
- [ ] 좁은 창(약 800px)과 넓은 창에서 겹치거나 잘리지 않는다
- [ ] 간격과 정렬이 이웃 요소와 같은 규칙을 따른다
- [ ] 요소가 다른 레이어에 가려지지 않는다(z-index, overflow)

## 상태

- [ ] 마우스 올림, 누름, 선택, 포커스, 비활성이 모두 구분된다
- [ ] 로딩, 비어 있음, 오류 화면이 있다
- [ ] 선택된 것이 무엇인지 한눈에 보인다

## 조작

- [ ] 커서 모양이 동작과 맞다(잡기, 누르기, 크기 조절, 글자 입력)
- [ ] 키보드만으로 쓸 수 있다(Tab, Enter, Esc)
- [ ] 끌기와 놓기에서 놓을 곳이 미리 보인다
- [ ] 실수한 동작을 되돌릴 수 있다

## 테마와 모션

- [ ] 밝은 테마와 어두운 테마 모두 확인했다
- [ ] 색과 크기를 직접 쓰지 않고 토큰을 썼다
- [ ] 움직임이 정해 둔 속도와 곡선을 따르고, 모션 끄기를 존중한다

## 글

- [ ] 버튼과 메뉴 문구가 짧고 동사로 끝난다
- [ ] 툴팁이 버튼이 무엇을 하는지 말해 준다

# 모션 가이드

움직임은 "무엇이 어디서 와서 어디로 갔는지"를 알려 줄 때만 써요. 꾸미려고 쓰지 않아요.

## 속도와 곡선

- 기본: 짧은 시간(약 200ms) 하나와 감속 곡선 하나만 쓴다. 토큰으로 정의한다(예: `--mae-dur`, `--mae-ease`)
- 큰 이동(화면 전환, 패널 열기)은 기본의 1.5배까지
- 설정에서 모션을 끄면 즉시 바뀐다(시간 0)

## 쓰는 곳

| 상황 | 움직임 |
|---|---|
| 나타남 (메뉴, 모달, 카드) | 살짝 위로 떠오르며 투명 → 불투명 |
| 접기·펼치기 | 자기 중심을 기준으로 크기 변화 |
| 위치 이동 | 출발점에서 도착점까지 이어서 |
| 마우스 올림 | 색과 테두리만. 크기는 거의 바꾸지 않는다 |
| 로딩 | 브랜드 로딩 표시 하나만. 여러 종류를 섞지 않는다 |

## 하지 않는 것

- 끌고 있는 요소에 전환 효과를 걸지 않는다(포인터보다 늦게 따라온다)
- 같은 화면에서 여러 요소를 제각각 움직이지 않는다
- 반복 애니메이션은 로딩처럼 "기다리는 중"일 때만

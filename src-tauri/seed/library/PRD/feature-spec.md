# 기능 명세 템플릿

PRD보다 작은 단위, 워커 한 명에게 맡길 기능 하나의 명세예요. 마에스트로가 일을 나눌 때 워커마다 이 형식으로 써서 첫 지시로 보내면 좋아요.

---

## 무엇을

한두 문장. 끝나면 사용자가 무엇을 할 수 있게 되는가.

## 범위

- **바꿀 곳:** 파일, 모듈
- **바꾸지 않을 곳:** 건드리면 안 되는 부분

## 동작

1. 사용자가 …하면
2. …가 보이고
3. …가 저장된다

경계 상황: 비어 있을 때, 아주 길 때, 실패했을 때, 동시에 일어날 때.

## 인터페이스

새로 생기거나 바뀌는 함수, 타입, 명령, API.

## 확인 방법

- 실행할 명령
- 눈으로 볼 것
- 추가할 테스트

## 끝나면 보고할 것

바꾼 파일, 확인 결과, 남은 위험, 후속 작업.

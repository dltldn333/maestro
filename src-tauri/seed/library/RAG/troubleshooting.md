# 문제 해결 기록 템플릿

한 번 겪은 문제를 다음 사람(또는 다음 에이전트)이 검색으로 바로 찾게 남겨요. 증상 문장과 오류 메시지를 그대로 적는 것이 핵심이에요.

---

## 증상

화면에 보인 것, 오류 메시지 원문 그대로.

```
(오류 메시지)
```

## 조건

언제 생기나. 운영체제, 버전, 순서, 설정.

## 원인

왜 생겼나. 확실하지 않으면 "추정"이라고 적는다.

## 해결

바꾼 코드나 설정, 실행한 명령.

## 다시 생기지 않게

추가한 테스트, 검사, 문서.

## 관련

관련 파일, 커밋, 문서.

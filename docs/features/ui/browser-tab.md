# 브라우저 탭 (시도했다가 뺀 기능)

## 요약

Orca나 Claude 데스크톱처럼 가운데 화면 탭에 진짜 브라우저를 띄우고, 페이지 요소를 골라 에이전트 채팅에 붙이는 기능을 만들었다가 문제가 많아 모두 뺐어요. 다시 만들 때 같은 실수를 피하려고 기록만 남겨요. 지금 코드에는 없어요.

## 동작

없음. 아래는 만들었던 모습이에요.

- 탭 막대의 지구본 버튼으로 브라우저 탭을 열고, 주소창·뒤로·앞으로·새로고침을 뒀어요.
- "요소 선택"으로 페이지 요소를 고르면 선택자, 텍스트, HTML을 에이전트 채팅 입력에 붙였어요.
- 에이전트 출력에 `http://localhost:포트`가 나오면 브라우저 탭을 자동으로 열려고 했어요.

## 구현

없음. 시도했던 구조:

- 탭은 `base`가 `maestro:browser`인 파일 탭으로 흉내 냈어요(탭 코드 재사용).
- 1차: Tauri 자식 웹뷰(`Window::add_child`). Cargo에 `unstable` 기능이 필요해요.
- 2차: 브라우저마다 테두리 없는 별도 창(`WebviewWindowBuilder` + `parent`)을 만들어 탭 영역 위에 0.25초마다 위치를 맞췄어요.
- 요소 선택: `initialization_script`로 선택 스크립트를 넣고, 결과는 가짜 주소(`https://maestro-pick.invalid/?d=…`)로 이동하는 척해서 `on_navigation`이 잡게 했어요(다른 사이트 페이지는 앱 IPC를 못 불러요).

## 결정 기록

실패한 점:

- **`unstable` 기능이 앱 전체를 깨뜨렸어요.** 이 기능을 켜면 Tauri가 앱 자신의 화면도 창 안의 자식 웹뷰로 만들어요(tauri-runtime-wry). 그러자 크기와 클릭 위치가 어긋나서 캔버스 블록이 안 보이고, 분할선과 설정 탭이 안 눌리고, 탭을 끌면 금지 표시가 떴어요. 브라우저 탭을 열지 않아도 생겨요.
- **별도 창 방식에서는 브라우저 탭을 열었다 닫으면 캔버스의 에이전트 블록이 사라졌어요.** 원인은 못 찾았어요(저장된 캔버스 파일에는 블록이 그대로 있었어요).
- **자동 열기가 동작하지 않았어요.** 채팅에서 localhost 주소가 언급돼도 탭이 뜨지 않았어요. 실시간 `agent://event`를 문자열로 바꿔 정규식으로 찾았는데, 원인은 확인하지 못했어요.

다시 한다면:

- iframe은 외부 사이트가 막고(`X-Frame-Options`), 다른 출처 페이지에 스크립트를 못 넣어 요소 선택이 안 돼요. 그래서 네이티브 웹뷰가 필요해요.
- `unstable`은 쓰지 말고, 별도 창 방식으로 하되 먼저 실제 앱에서 열고 닫기, 창 이동, 포커스를 하나씩 확인하면서 만들어요.
- 웹뷰는 HTML 위에 떠서 캔버스 줌이나 겹침을 따라갈 수 없어요. 캔버스 블록이 아니라 탭에만 둬요.

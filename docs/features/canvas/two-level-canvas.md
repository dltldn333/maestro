# 캔버스 구성

## 요약

캔버스는 세 가지예요.
- **프로젝트 캔버스(`ProjectMap`):** 사이드바에서 프로젝트를 누르면 나와요. 구조만 보여 주고, 항상 트리 모양이에요.
- **마에스트로 캔버스:** 마에스트로 에이전트 블록 아래에 워크트리 카드들을 놓고 연결선과 참조를 편집해요.
- **워크트리 캔버스:** 워크트리 하나의 에이전트 블록과 프롬프트 블록을 놓아요.

워크트리에 들어가면 기본은 전체 화면 에이전트이고, 캔버스는 전환해서 봐요.

## 동작

**프로젝트 캔버스**
- 카드(`structure_card`)마다 이름, 상태, 외부 배지, 에이전트 로고, 설명, 참조 문서·페르소나 칩, 브랜치와 워커 수가 보여요.
- 카드를 더블클릭하면 그 워크트리로 들어가요.
- "+" 칩을 누르면 참조 문서 선택 창(`RefPicker`)이 열려요.
- 위쪽 버튼:
  - 마에스트로가 있으면 "♛ 마에스트로 캔버스"
  - 없으면 "♛ 마에스트로 만들기"
- 여기서는 연결을 바꾸지 않아요.

**마에스트로 캔버스**(`Canvas`, `scope` = 마에스트로)
- 맨 위에 마에스트로 에이전트 블록이 있고, 아래에 워크트리 카드(`worktree_card`)가 놓여요.
- 워크트리 카드에 보이는 것:
  - 상태와 변경된 파일 수
  - 최근 답변 요약 → [답변 요약](../agents/answer-summaries.md)
  - 바로 지시를 보내는 작은 입력창
- 연결:
  - 계층선(마에스트로 → 워커)과 참조선(마크다운 → 에이전트)을 이 캔버스에서 만들고 끊어요.
  - 선을 고르면 ×가 나와요. ×를 누르거나 Delete 키로 끊어요.
  - 카드에서 선을 끌어 빈 곳에 놓으면 그 카드의 워커로 새 워크트리를 만들어요. → [워커 계층](../orchestration/worker-hierarchy.md)
- 버튼: "+ 워커", "+ 프롬프트 블록", "문서"(Maestro 문서를 끌어와 참조 블록으로)
- 카드를 더블클릭하면 그 워크트리로 들어가요.

**워크트리 화면**
- 기본은 전체 화면(`AgentFull`)이에요. Claude Code 앱처럼 에이전트 하나가 화면을 채워요.
- "전체 화면 / 캔버스" 전환(`LayoutToggle`)은 워크트리 탭마다 따로예요(탭의 `layout`, `setTabLayout`). 마지막으로 고른 값은 설정 `agentLayout`에 남아서, 새로 여는 탭만 그걸로 열려요.
- 캔버스에서는 에이전트 블록(`pty_terminal_node`)과 프롬프트 블록을 자유롭게 놓아요. 블록 오른쪽 아래 모서리를 끌어 크기를 바꿔요.
- 뒤로 버튼으로 프로젝트로 돌아가요.

**공통**
- 블록 위치는 격자(`GRID`)에 맞춰져요.
- 캔버스마다 배치와 화면 위치가 저장돼요.
- 처음 열거나 트리 배치 전에 저장된 캔버스는 한 번 트리로 자동 배치돼요(`treeLayout`).
  - 마에스트로가 맨 위, 워커는 부모 아래, 형제는 옆으로 놓여요.
  - 상위가 없는 워크트리도 마에스트로 아래에 선 없이 놓여요.
- 연결점은 블록 네 변에 있어요. 선은 두 블록이 마주 보는 변에서 나가고 들어와요(`facingSides`).
- **에이전트 블록 접기**: 에이전트 블록 헤더의 접기 버튼을 누르면 작은 블록(336×84)이 돼요. 블록 가운데를 기준으로 줄어들고 펼칠 때도 가운데에서 커지며(격자에 맞추면 가운데에서 벗어나서 이때만 맞추지 않아요), 설정의 모션 속도를 따라 움직여요. 상태 점, 에이전트 로고, 이름, 그 아래 페르소나·참조 문서 태그(최대 두 줄)만 보이고, 작업 중이면 로딩 표시, 승인을 기다리면 "승인 대기"가 붙어요. 이 블록을 누르면 아래 입력창이 열리고, 다시 누르면 닫혀요. 알약의 펼치기 버튼을 누르면 접기 전 크기의 창으로 돌아가요. 접은 상태는 캔버스와 함께 저장돼요.

- **아래 입력창**: 에이전트 캔버스 맨 아래 가운데에 마에스트로 로고 버튼이 있어요. 마우스를 올리면 로고가 로딩 모양으로 움직이고, 누르면 그 위에 이 캔버스 에이전트(마에스트로 캔버스면 마에스트로)에게 보내는 입력창(승인 카드 포함)이 열려요. 입력창 위쪽에는 상태 점, 에이전트 이름, LLM 로고와 이름, 닫기(×)가 있어요. 입력창 폭은 왼쪽 줌 바와 오른쪽 미니맵을 피하도록 캔버스 폭에 맞춰 줄어요(최대 680px). 캔버스의 다른 곳을 눌러도 닫히지 않고, 같은 버튼(또는 접힌 에이전트 블록)을 다시 눌러야 닫혀요.
- **아래 입력창에서 대화 보기**: 입력창 맨 위 손잡이를 끌어 올리면 그만큼 대화 내용이 입력창 위에 보여요(최대 화면 높이의 60%). 끌어 내리면 줄고, 조금만 남기면 닫혀요. 헤더의 화살표 버튼(또는 손잡이 더블클릭)은 가장 작은 높이(160px)로 열고 닫아요. 높이는 에이전트마다 기억해요.
- **전체 화면으로**: 아래 입력창 헤더의 전체 화면 버튼, 또는 캔버스 에이전트 블록의 헤더(접힌 블록이면 블록)를 더블클릭하면 그 에이전트 전체 화면으로 넘어가요. 채팅 안을 더블클릭하는 건 글자 선택이라 넘어가지 않아요. 캔버스로 돌아오면 아래 입력창이 열려 있던 그대로예요(앱을 켜 둔 동안 캔버스마다 기억).
- **선택을 함께 보내기**: 캔버스에서 블록(워커, 문서, 프롬프트 블록)을 선택한 채 아래 입력창을 쓰면, 입력창 위에 "선택 N개" 칩과 이름들이 보여요. 이대로 보내면 메시지 앞에 `[캔버스에서 선택한 블록]` 목록이 붙어요(슬래시 명령과 `!` 명령에는 안 붙어요). 칩의 ×를 누르면 캔버스의 선택도 함께 풀려요(그래서 `maestro selection`도 비어요). 에이전트는 `maestro selection`으로도 지금 선택을 읽을 수 있어요. → [maestro CLI](../orchestration/maestro-cli.md)
- **워커 카드 접기**: 마에스트로 캔버스의 워커 카드도 헤더의 접기 버튼으로 간소화할 수 있어요. 헤더(이름, 에이전트), 연결된 페르소나(`♟`)와 참조 문서(`≡`) 태그(최대 두 줄, 나머지는 잘리고 마우스를 올리면 전부 보여요), 아래 바로 지시 입력창만 남고 설명, 페르소나, 변경 수, 답변 요약은 숨겨요(폭 312, 높이는 내용만큼: 태그가 없으면 헤더 한 줄, 있으면 이름 아래 태그 줄만큼 길어져요. 카드가 자기 높이를 재서 블록 크기를 맞춰요). 승인을 기다리면 헤더에 "승인 대기"가 보여요. 같은 버튼으로 다시 펼쳐요.

## 구현

- 화면 고르기(App.tsx):
  - 선택 없음 → `ProjectMap`
  - 마에스트로 → `Canvas`
  - 워크트리 → `agentLayout`이 `full`이면 `AgentFull`, 아니면 `Canvas`
- 저장: `load_canvas_state` / `save_canvas_state(project_root, key)`
  - 저장 위치는 `~/.maestro/projects/<프로젝트>/canvases/<key>.json`이에요. → [저장 위치](../../reference/storage-layout.md)
  - 형식은 `CanvasStateSchema`(types.ts)예요. `tree: 1`이면 트리 배치를 한 번 했다는 뜻이에요.
- 노드 종류: `nodeTypes = { prompt_input_primitive, pty_terminal_node, worktree_card, markdown_block }`
- 선 종류: `CanvasEdge.data.kind`
  - `command_pipe`(프롬프트 → 에이전트, 캔버스에 저장)
  - `orchestrates`(계층), `reference`(참조) — 이 둘은 에이전트 메타에서 그려요
- 연결 모드는 `ConnectionMode.Loose`예요. 네 변의 연결점이 모두 `source` 타입이어도 서로 이어져요.
- 줌을 많이 줄이면(`LOD_ZOOM` 아래) 블록이 가벼운 모양으로 그려져요.
- 접기: 노드 데이터의 `compact`(접힘)와 `full`(펼칠 때 크기). `AgentChip`이 알약, `AgentBar`가 아래 입력창이에요(AgentNode.tsx). 캔버스의 `barOpen` 상태가 아래 입력창을 열고 닫아요(모듈의 `barOpen` 지도에 캔버스별로, 대화 높이는 `peeks`에 에이전트별로 남겨서 전체 화면에 다녀와도 그대로예요). 전체 화면 전환은 Workspace가 넘긴 `onFull`(`setTabLayout(..., "full")`)이에요. `Panel position="bottom-center"`에 `AgentBar`와 로고 버튼(`BarButton`, 마우스를 올린 동안만 `LogoMotion`이 움직이고 끝나면 다시 그려서 로고 모양으로 멈춰요)이 있고, 접힌 에이전트 블록 클릭(`onNodeClick`, 끌기 뒤에는 오지 않아요)도 같은 상태를 바꿔요. 입력창은 채팅 화면과 같은 `Composer`이고, 에이전트가 아직 안 켜졌으면 `useAgentBoot`로 켜요. 접고 펼치는 움직임은 `useFold`(AgentNode.tsx)가 맡아요: 크기 차이의 절반만큼 위치를 옮기고, 그동안만 `.folding` 전환 클래스를 붙여요. 워커 카드는 `data.compact`와 `CARD_COMPACT`(WorktreeCard.tsx)를 써요. 접힌 블록 크기는 `COMPACT_SIZE`이고 `normalize`가 불러올 때 그 크기로 맞춰요.

## 결정 기록

- 처음에는 캔버스가 하나였어요. "프로젝트 → 워크트리 블록 → 들어가기" 구조 요청으로 두 단계가 됐고, 이후 마에스트로 캔버스가 더해졌어요.
- 왼쪽에 하나 남아 있던 옛 입력 연결점은 네 변 연결점과 겹쳐서 지웠어요(2026-11-01).

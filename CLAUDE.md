# Maestro

Tauri v2 (Rust, `src-tauri/`) + React (`src/`) desktop app that runs CLI coding agents in git worktrees on canvases.

## Docs

- Feature and architecture docs live in `docs/` (Korean, one topic per file, frontmatter + fixed sections). Read `docs/README.md` for the format.
- Look there first when you need to know how something works or where it lives.
- When you add or change a feature, update or add its doc in the same change, and bump `updated:`.
